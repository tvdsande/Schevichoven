# Quickscan financiële positie

Instrument dat uit de jaarrekeningen van drie boekjaren en enkele operationele antwoorden een gestandaardiseerd rapport van drie tot vijf pagina's opstelt, met vaste rekenregels en een taalmodel uitsluitend voor het uitlezen en rubriceren. Ontwikkeld ten behoeve van Schevichoven Groeit.

Status: fase 0 (fundament). Er is nog geen code.

- `CLAUDE.md`: harde regels en werkwijze
- `docs/bouwplan.md`: fasering, architectuur en open vragen
- `docs/rekenregels.md`: definities en formules
- `fixtures/de-hoge-kamp.json`: fictief voorbeeldbedrijf (melkvee), gouden referentie voor de tests
